# API structure

## Authentication

- POST /api/users/register/
- POST /api/users/login/
- POST /api/users/logout/

## Student APIs

- GET /api/students/
- POST /api/students/

## Company APIs

- GET /api/companies/
- POST /api/companies/

## Scheme APIs

- GET /api/schemes/
- POST /api/schemes/

## Recommendation APIs

- GET /api/recommendations/
- POST /api/recommendations/

## AI Copilot APIs

- GET /api/ai-copilot/
- POST /api/ai-copilot/

## Admin APIs

- GET /api/admin/schemes/
- PUT /api/admin/schemes/<id>/
- DELETE /api/admin/schemes/<id>/
